# Smart Academic Manager (SAM)

A scalable, extendable academic operations platform built with the MERN stack (MongoDB, Express.js, React 18+, Node.js) and TypeScript.

## Core Modules
1. **Schedule Generator & Editor**
   - Automated timetable generation with hard and soft constraint satisfaction.
   - Interactive administrative drag-and-drop schedule visualizer/editor.
   - Professor soft constraints, temporary class cancellation, and rescheduling with collision checks.
   - Student read-only timetable views.
2. **Attendance Records Keeper**
   - Administrative entity and enrollment management (Students, Professors, Batches, Classrooms).
   - Real-time timetable-linked attendance marking for professors.
   - Student attendance percentage tracking, defaulter alerts, and audit logs.
